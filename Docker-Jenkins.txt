1. pull the jenkins image

docker pull jenkins/jenkins:lts-jdk21

2. 
Function:

This command creates and starts a Jenkins Docker container from
 the Jenkins image you already downloaded.
breakdown
| Part                                | Function                                                                              |
| ----------------------------------- | ------------------------------------------------------------------------------------- |
| `docker run`                        | Creates a new container and starts it                                                 |
| `-d`                                | Runs Jenkins in the background (detached mode)                                        |
| `--name jenkins`                    | Gives the container the name `jenkins` so we can easily manage it later               |
| `-p 8080:8080`                      | Maps Jenkins web interface port from the container to your PC (`localhost:8080`)      |
| `-p 50000:50000`                    | Opens Jenkins agent/remoting communication port (used for connecting build agents)    |
| `-v jenkins_home:/var/jenkins_home` | Connects your Docker volume to Jenkins storage so jobs, plugins, and settings persist |
| `jenkins/jenkins:lts-jdk21`         | The Jenkins image to use (Jenkins LTS running on Java 21)                             |


docker run -d --name jenkins -p 8080:8080 -p 50000:50000 -v jenkins_home:/var/jenkins_home jenkins/jenkins:lts-jdk21
